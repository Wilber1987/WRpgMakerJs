Introducción

Un motor de juego open world web-first con integración completa de novelas visuales

🗺️

Mapas Explorables

Sistema de mapas tile-based con colisiones, objetos interactivos y NPCs posicionables con coordenadas precisas.

⚔️

Batalla por Turnos

Sistema de combate táctico con habilidades, estadísticas de personajes y IA enemiga configurable.

💬

Diálogos VN

Integración nativa con Visual Novel Engine para escenas narrativas, opciones y ramificaciones.

🎭

Personajes Dinámicos

Sistema de personajes con sprites animados, estados emocionales y comportamientos personalizados.

💾

Guardado Automático

Persistencia de estado del juego usando localStorage con soporte para múltiples slots.

🎨

UI Personalizable

Componentes de interfaz modulares con Web Components para menús, HUD y pantallas.

ℹ️
Nota: Este motor está diseñado para funcionar junto con VNEngine. La integración permite transiciones fluidas entre exploración open world y escenas de novela visual.

OpenWorldEngineView

Web Component principal que contiene todo el motor de juego. Maneja el canvas, UI y coordinación entre sistemas.

Uso Básico 
const oppenWorldEngine = new OpenWorldEngineView({
    character: Alexandra  // Personaje jugador
});

// Iniciar el motor
oppenWorldEngine.Start();

// Ir a un mapa específico
oppenWorldEngine.GoToMap("Ciudad1");

// Registrar personaje para batalla
oppenWorldEngine.RegisterCharacter(DanaCharacter);
DanaCharacter.partyPosition = 1;

GameEngine

Corazón del motor. Maneja el game loop, input, colisiones, renderizado y lógica del juego.

Acceder al GameEngine 
// Acceso desde OpenWorldEngineView
const engine = oppenWorldEngine.GameEngine;

// Cambiar mapa
engine.GoToMap("Ciudad1");

// Obtener mapa actual
const currentMap = engine.currentMap;

// Acceder al sistema de batalla
const battleSystem = engine.battleSystem;

GameMap

Representa un mapa del juego con tiles, objetos, NPCs y configuración de fondo.

Crear un Mapa 
const ciudad1 = new GameMap('Ciudad1', 64, 36, {
    spawnX: 23,   // Punto de inicio del jugador
    spawnY: 16,
    battleBackgrond: getAsset("City1/battleBg.png"),
    bgColor: '#666',
    NPCs: [npc1, DanaCharacter],
    backgroundImage: getAsset("City1/map1.png")
});

// Añadir al motor
oppenWorldEngine.AddMap(ciudad1);

import { CharacterModel } from "../../Core/Common/CharacterModel.js";

export class DanaCharacterModel extends CharacterModel {
    Name = "Dana";
    
    // Estados visuales del personaje
    State = {
        Default: "Character/dana_default",
        Happy: "Character/dana_happy",
        Sad: "Character/dana_sad",
        Angry: "Character/dana_angry"
    };

    // Configuración de batalla
    Stats = {
        hp: 100,
        maxHp: 100,
        strength: 15,
        speed: 10
    };

    // Habilidades especiales
    Skills = [
        { name: "Ataque Fuerte", damage: 25 },
        { name: "Curación", heal: 30 }
    ];
}

// Exportar instancia singleton
export const DanaCharacter = new DanaCharacterModel();

Sistema de Mapas

Crea mundos explorables con objetos interactivos

Crear un Mapa

Maps/Ciudad1.js 
import { GameMap, BlockObject } from "../../Core/OppenWorld/OpenWordModules/Models.js";

const getAsset = (asset) => "./Media/assets/Maps/" + asset;

const ciudad1 = new GameMap('Ciudad1', 64, 36, {
    spawnX: 23,
    spawnY: 16,
    bgColor: '#666',
    NPCs: [npc1, DanaCharacter],
    backgroundImage: getAsset("City1/map1.png")
});

// Añadir objetos al mapa
ciudad1.addObject(new BlockObject(23, 15, 1, 1, {
    color: '#FFD700',
    Action: () => {
        battle();  // Iniciar batalla
    }
}));

// Añadir al motor
oppenWorldEngine.AddMap(ciudad1);

BlockObject - Objetos Interactivos

Los BlockObjects son elementos colocados en el mapa que pueden tener colisión, iconos visuales y acciones.

Propiedad Tipo Descripción
x number Posición X en tiles
y number Posición Y en tiles
w number Ancho en tiles
h number Alto en tiles
color string Color de renderizado (opcional)
icon string Ruta a imagen del objeto
Action Function Función al interactuar
autoTrigger boolean Activar automáticamente al pisar

Colisiones y Bloques Invisibles

Crear Paredes Invisibles 
// Bloque de colisión invisible (sin color)
ciudad1.addObject(new BlockObject(22, 1, 1, 1, {
    // Sin color = invisible pero con colisión
}));

// Múltiples bloques para crear paredes
for (let i = 0; i < 10; i++) {
    ciudad1.addObject(new BlockObject(i, 0, 1, 1, {}));
}

Sistema de Batalla

Combate por turnos con habilidades y estadísticas

Iniciar Batalla

Iniciar Combate 
const battle = () => {
    // Crear enemigos
    const enemies = [
        new CharacterModel({
            Name: "goblin",
            Stats: {
                hp: 15,
                maxHp: 15,
                strength: 3,
                speed: 3,
            },
            isEnemy: true,
            Skills: [oppenWorldEngine.GameEngine.battleSystem.createBasicAttack()]
        })
    ];

    // Obtener equipo del jugador
    const party = oppenWorldEngine.GetParty(npc1);

    // Iniciar batalla
    oppenWorldEngine.StartBattle(enemies, party);
};

Configurar Equipo de Batalla

Registro de Personajes 
// Registrar personaje para batalla
oppenWorldEngine.RegisterCharacter(DanaCharacter);

// Asignar posición en el equipo (0-3)
DanaCharacter.partyPosition = 1;
Alexandra.partyPosition = 0;

// Iniciar batalla sin especificar equipo
// Usará automáticamente los personajes registrados
oppenWorldEngine.StartBattle(enemies);

Estadística Descripción Valor Típico

maxHp Puntos de vida máximos 100-1500
strength Daño base de ataques 5-100
speed Determina orden de turno 1-50

Integración con VNEngine

Transiciones fluidas entre exploración y narrativa

Definir Escenas de Novela Visual

Escena de Diálogo 
vnEngine.defineScene("danaJoinHistory", [
    Scene.Show("assets/Maps/City1/scene1.png"),
    DanaCharacter.Show(),
    Flow.Choice([
        Flow.Action("Saludar", [
            Alexandra.Say("Hola"),
            DanaCharacter.Say("Hola"),
            () => vnEngine.Disconnect()
        ]),
        Flow.Action("Solicitar que se una al equipo", [
            Alexandra.Say("Hola, escuche que necesitas un equipo"),
            DanaCharacter.Say("Si yo estoy buscando equipo"),
            DanaCharacter.SetVar("Join", true),
            () => {
                oppenWorldEngine.RegisterCharacter(DanaCharacter);
                DanaCharacter.partyPosition = 1;
                vnEngine.Disconnect()
            }
        ], { render: Flow.Var("DanaJoin", "==", false) })
    ])
]);

Transición OpenWorld ↔ VN

Flujo de Transición 
// Desde OpenWorld a VN (interacción con NPC)
const npc1 = new CharacterModel({
    Name: "Mage",
    MapData: [{
        name: "Ciudad1", 
        posX: 24, 
        posY: 14, 
        action: () => {
            vnEngine.startScene("npc1Chat");  // Inicia escena VN
        }
    }]
});

// Desde VN a OpenWorld (volver al mapa)
vnEngine.defineScene("start_game", [
    Scene.Show("assets/Maps/City1/scene1.png"),
    Alexandra.Say("Inicie la aventura"),
    () => {
        vnEngine.Disconnect();  // Cierra VN
        oppenWorldEngine.GoToMap("Ciudad1");  // Vuelve al mapa
    }
]);
💡
Consejo: Usa vnEngine.Disconnect() para cerrar la escena de novela visual y volver al control del mapa. El estado del juego se mantiene entre transiciones.

GameStartScreen

Pantalla de inicio con opciones de nuevo juego, continuar, guardar y opciones.

import { GameStartScreen } from "./Core/OppenWorld/OpenWordModules/GameStartScreen.js";

const screenOptions = [
    {
        name: "New Game", 
        startGame: true, 
        action: () => {
            oppenWorldEngine.GoToMap("Ciudad1");
        }
    }, 
    {
        name: "Continuar", 
        startGame: false, 
        action: (screenView) => {
            saveSystem.showSaveLoadScreen(true, () => { 
                new GameMenu(screenView).Connect(); 
            });
        }
    },
    {
        name: "Test Scene", 
        startGame: true, 
        action: () => {
            vnEngine.startScene("start_game");
        }
    }
];

const screenView = new GameStartScreen({
    screenOptions: screenOptions
});

oppenWorldEngine.screenView = screenView;
document.body.append(screenView);

Referencia API Completa

Documentación detallada de todas las clases y métodos

OpenWorldEngineView

Método Parámetros Retorna Descripción
constructor {character: CharacterModel} OpenWorldEngineView Crea instancia del motor
Start() - void Inicia el motor y muestra pantalla de inicio
GoToMap(mapName) string void Cambia al mapa especificado
AddMap(map) GameMap void Añade un mapa al motor
RegisterCharacter(char) CharacterModel void Registra personaje para batalla
GetParty(leader) CharacterModel CharacterModel[] Obtiene equipo de batalla
StartBattle(enemies, party) CharacterModel[], CharacterModel[] void Inicia sistema de batalla

GameEngine

Método Parámetros Retorna Descripción
addMap(map) GameMap void Añade mapa al diccionario
GoToMap(name, pos) string, {x, y} void Cambia mapa y posiciona jugador
update(ts) number void Game loop principal
draw() - void Renderiza frame actual

GameMap

Método Parámetros Retorna Descripción
constructor name, w, h, opts GameMap Crea nuevo mapa
addObject(obj) BlockObject void Añade objeto al mapa
addNPC(npc) CharacterModel void Añade NPC al mapa
isBlocked(tx, ty) number, number boolean Verifica si tile está bloqueado
setBackgroundImage(img) Image|string void Establece imagen de fondo

CharacterModel

Método Parámetros Retorna Descripción
constructor props CharacterModel Crea nuevo personaje
Show(state, position) string, string Object Muestra personaje en VN
ShowR(state) string Object Muestra a la derecha
ShowL(state) string Object Muestra a la izquierda
Hide() - Object Oculta personaje
Say(text, audio) string, string Object Diálogo del personaje
GetVar(name) string any Obtiene variable del juego
SetVar(name, value) string, any Object Establece variable
follow(character) CharacterModel void Hace que siga a otro personaje

app.js - Configuración Completa 
// Importaciones
import { CharacterModel, CharacterRegistry } from "./Core/Common/CharacterModel.js";
import { GameMenu } from "./Core/Common/UIComponents/GameMenu.js";
import { GameStartScreen } from "./Core/OppenWorld/OpenWordModules/GameStartScreen.js";
import { BlockObject, GameMap } from "./Core/OppenWorld/OpenWordModules/Models.js";
import { OpenWorldEngineView } from "./Core/OppenWorld/OpenWorldEngineView.js";
import { saveSystem, vnEngine } from "./Core/VisualNovel/VisualNovelEngine.js";
import { Dialogue, Flow, Scene } from "./Core/VisualNovel/VisualNovelModules.js";
import { Alexandra } from "./Characters/AlexandraCharacter.js";
import { DanaCharacter } from "./Characters/DanaCharacter.js";

// Helper para rutas de assets
const getAsset = (asset) => "./Media/assets/Maps/" + asset;

// Registrar personajes singleton
CharacterRegistry.registerSingleton(Alexandra);
CharacterRegistry.registerSingleton(DanaCharacter);

// Crear NPC
const npc1 = new CharacterModel({
    Name: "Mage",
    MapData: [{
        name: "Ciudad1", 
        posX: 24, 
        posY: 14, 
        action: () => vnEngine.startScene("npc1Chat")
    }]
});

// Configurar posición de Dana en mapa
DanaCharacter.MapData.push({
    name: "Ciudad1", 
    posX: 25, 
    posY: 12, 
    action: () => vnEngine.startScene("danaJoinHistory")
});

// Definir escena VN
vnEngine.defineScene("danaJoinHistory", [
    Scene.Show(getAsset("City1/scene1.png")),
    DanaCharacter.Show(),
    Flow.Choice([
        Flow.Action("Saludar", [
            Alexandra.Say("Hola"),
            DanaCharacter.Say("Hola"),
            () => vnEngine.Disconnect()
        ]),
        Flow.Action("Unir al equipo", [
            DanaCharacter.SetVar("Join", true),
            () => {
                oppenWorldEngine.RegisterCharacter(DanaCharacter);
                DanaCharacter.partyPosition = 1;
                vnEngine.Disconnect();
            }
        ])
    ])
]);

// Crear motor
const oppenWorldEngine = new OpenWorldEngineView({
    character: Alexandra
});

// Crear mapa
const ciudad1 = new GameMap('Ciudad1', 64, 36, {
    spawnX: 23,
    spawnY: 16,
    bgColor: '#666',
    NPCs: [npc1, DanaCharacter],
    backgroundImage: getAsset("City1/map1.png")
});

// Añadir objeto interactivo
ciudad1.addObject(new BlockObject(23, 15, 1, 1, {
    color: '#FFD700',
    Action: () => battle()
}));

// Añadir mapa al motor
oppenWorldEngine.AddMap(ciudad1);

// Función de batalla
const battle = () => {
    const enemies = [
        new CharacterModel({
            Name: "goblin",
            Stats: { hp: 15, maxHp: 15, strength: 3, speed: 3 },
            isEnemy: true
        })
    ];
    oppenWorldEngine.StartBattle(enemies);
};

// Configurar pantalla de inicio
const screenOptions = [
    {
        name: "New Game", 
        startGame: true, 
        action: () => {
            oppenWorldEngine.GoToMap("Ciudad1");
            new GameMenu().Connect();
        }
    }
];

const screenView = new GameStartScreen({ screenOptions });
oppenWorldEngine.screenView = screenView;
document.body.append(screenView);
