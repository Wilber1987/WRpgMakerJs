WOpenWorldJS

Motor de juego Open World basado en JavaScript para crear experiencias RPG interactivas con sistema de batalla, novelas visuales y exploración de mapas.

Ver Repositorio GitHub

📦 Instalación del Proyecto

Para comenzar a trabajar con WOpenWorldJS, es necesario clonar el repositorio incluyendo todos sus submódulos. El proyecto utiliza una arquitectura modular que requiere dependencias externas.

Importante: El comando de clonación debe incluir la bandera --recurse-submodules para descargar correctamente todas las dependencias del proyecto.
Terminal - Clonar repositorio
git clone --recurse-submodules -j8 https://github.com/Wilber1987/WOpenWorldJs

Este comando descarga el código fuente principal junto con todos los módulos necesarios para el funcionamiento del motor de juego.

🏗️ Arquitectura del Motor

WOpenWorldJS está construido sobre una arquitectura basada en componentes web (Web Components) que permite una integración sencilla con cualquier aplicación web moderna.

OpenWorldEngineView

Componente principal que gestiona el ciclo de vida del juego, renderizado en canvas y coordinación entre sistemas.

GameEngine

Núcleo lógico que maneja el estado del juego, colisiones, movimiento de personajes y actualizaciones por frame.

CharacterModel

Sistema de personajes con soporte para estadísticas, inventario, habilidades y animaciones sprite-based.

Visual Novel Engine

Motor integrado para crear secuencias narrativas con diálogos, elecciones y escenas cinemáticas.

Battle System

Sistema de combate por turnos con gestión de partidos, enemigos y habilidades especiales.

Map System

Gestión de múltiples mapas con colisiones, objetos interactivos y NPCs posicionados dinámicamente.

🎮 Configuración Básica del Juego

La inicialización del motor requiere configurar el componente principal, definir personajes y crear al menos un mapa para explorar.

1. Inicialización del Motor

El punto de entrada principal es la creación de una instancia de OpenWorldEngineView, que actúa como contenedor de todos los sistemas del juego.

main.js - Inicialización del motor
// Crear instancia del motor con personaje principal
const oppenWorldEngine = new OpenWorldEngineView({
    character: Warrior // Personaje principal definido previamente
});

// El motor se appendea al DOM cuando esté listo
document.body.append(oppenWorldEngine);

2. Definición de Personajes

Los personajes se crean extendiendo la clase CharacterModel, permitiendo personalizar estadísticas, sprites y comportamientos únicos.

Characters/Warrior.js - Definición de personaje
class WarriorModel extends CharacterModel {
    constructor(props) {
        // Configurar frames de animación específicos
        props.SpritesFrames = { attack: 25 }
        
        // Definir estadísticas base del personaje
        props.Stats = {
            hp: 30,           // Puntos de vida
            maxHp: 30,        // Vida máxima
            strength: 10,     // Fuerza de ataque
            speed: 3000,      // Velocidad de movimiento
        }
        
        super(props)
        
        // Asignar habilidades especiales
        this.Skills = [
            new SkillModel({ numberTargets: 100 })
        ]
    }
}

// Crear instancia singleton del guerrero
export const Warrior = new WarriorModel({});

// Registrar en el sistema para persistencia
CharacterRegistry.registerSingleton(Warrior);

🗺️ Creación de Mapas

Los mapas son el escenario donde ocurre la acción del juego. Cada mapa define dimensiones, fondo, puntos de spawn y objetos interactivos.

Estructura de un Mapa

Un mapa se crea instanciando la clase GameMap con parámetros específicos de configuración.

Maps/Ciudad1.js - Creación de mapa
// Función auxiliar para rutas de assets
const getAsset = (asset) => "./Media/assets/" + asset;

// Crear mapa Ciudad1 con dimensiones 64x36 tiles
const ciudad1 = new GameMap('Ciudad1', 64, 36, {
    spawnX: 23,              // Coordenada X de inicio del jugador
    spawnY: 16,              // Coordenada Y de inicio del jugador
    battleBackgrond: getAsset("Maps/City1/battleBg.png"), // Fondo de batalla
    bgColor: '#666',         // Color de fondo por defecto
    NPCs: [npc1, DanaCharacter], // NPCs presentes en este mapa
    backgroundImage: getAsset("Maps/City1/map1.png") // Imagen de fondo del mapa
});

Agregar Objetos al Mapa

Los objetos interactivos se añaden usando la clase BlockObject, que puede representar desde cofres hasta puertas o zonas de colisión.

Maps/Ciudad1.js - Agregar objetos
// Cofre interactivo en posición (19, 13)
ciudad1.addObject(new BlockObject(19, 13, 1, 1, {
    icon: getAsset("items/chest.png"), // Imagen del objeto
    Action: () => {
        console.log("Cofre abierto - iniciar batalla");
        battle() // Disparar evento de batalla
    }
}));

// Bloques de colisión invisibles para delimitar áreas
ciudad1.addObject(new BlockObject(22, 1, 1, 1, {
    // Sin color ni icono = objeto invisible pero sólido
}));
Nota: Los objetos sin propiedades visuales (color/icon) funcionan como colisionadores invisibles, útiles para crear paredes o áreas restringidas.

💬 Sistema de Novela Visual

El motor incluye un sistema completo para crear secuencias narrativas con diálogos, elecciones ramificadas y cambios de estado del juego.

Definición de Escenas

Las escenas se definen usando el vnEngine y pueden incluir mostrar personajes, diálogos y opciones de elección.

Scenes/Historia.js - Escena narrativa
vnEngine.defineScene("danaJoinHistory", [
    // Mostrar fondo de escena
    Scene.Show("assets/Maps/City1/scene1.png"),
    
    // Mostrar personaje en pantalla
    DanaCharacter.Show(),
    
    // Crear menú de elecciones
    Flow.Choice([
        // Opción 1: Saludar
        Flow.Action("Saludar", [
            Warrior.Say("Hola"),
            DanaCharacter.Say("Hola"),
            () => vnEngine.Disconnect() // Cerrar escena
        ]),
        
        // Opción 2: Reclutar (solo si no se ha unido)
        Flow.Action("Solicitar que se una al equipo", [
            Warrior.Say("Hola, escuche que necesitas un equipo"),
            DanaCharacter.Say("Si yo estoy buscando equipo"),
            Warrior.Say("Excelente, unete ami"),
            DanaCharacter.Say("Claro"),
            
            // Cambiar variable de estado
            DanaCharacter.SetVar("Join", true),
            
            // Registrar personaje en el partido
            () => {
                oppenWorldEngine.RegisterCharacter(DanaCharacter);
                DanaCharacter.partyPosition = 1;
                vnEngine.Disconnect()
            }
        ], { render: Flow.Var("DanaJoin", "==", false) }), // Condición de visualización
        
        // Opción 3: Seguir (solo si ya se unió)
        Flow.Action("Solicitar que te siga", [
            Warrior.Say("Sigueme"),
            DanaCharacter.Say("Claro"),
            () => {
                DanaCharacter.follow(Warrior);
                vnEngine.Disconnect()
            }
        ], { render: Flow.Var("DanaJoin", "==", true) })
    ])
]);

⚔️ Sistema de Batalla

El sistema de combate permite enfrentamientos por turnos entre el partido del jugador y grupos de enemigos, con gestión de habilidades y estadísticas.

Iniciar una Batalla

Las batallas se pueden llamarse desde cualquier parte del código, típicamente desde eventos, interacciones con objetos o NPCs.

Battle/Sistema.js - Función de batalla
const battle = () => {
    // Crear array de enemigos
    const enemies = [
        new CharacterModel({
            Name: "goblin",
            Stats: {
                hp: 15,
                maxHp: 15,
                strength: 3,
                speed: 3,
            },
            isEnemy: true, // Marcar como enemigo
            SpritesFrames: { attack: 25 },
            Skills: [oppenWorldEngine.GameEngine.battleSystem.createBasicAttack()]
        }),
        // ... más enemigos
    ];

    // Obtener partido actual (personajes registrados con partyPosition)
    const partyDePrueba = oppenWorldEngine.GetParty(npc1);

    // Iniciar batalla con enemigos y partido
    oppenWorldEngine.StartBattle(enemies, partyDePrueba);
}
Interfaz de sistema de batalla por turnos
Importante: Los personajes deben tener asignada la propiedad partyPosition para ser incluidos automáticamente en el partido de batalla.

🖥️ Pantalla de Inicio

La pantalla inicial del juego se gestiona mediante el componente GameStartScreen, que permite configurar múltiples opciones de menú.

UI/PantallaInicio.js - Configuración de menú
// Definir opciones del menú principal
const screenOptions = [
    {
        name: "New Game", 
        startGame: true, 
        action: () => {
            oppenWorldEngine.GoToMap("Ciudad1")
            new GameMenu().Connect()
        }
    }, 
    {
        name: "Continuar", 
        startGame: false, 
        action: (screenView) => {
            saveSystem.showSaveLoadScreen(true, () => { 
                new GameMenu(screenView).Connect() 
            });
        }
    }, 
    {
        name: "Test 2", 
        startGame: true, 
        action: () => {
            vnEngine.startScene("start_game");
        }
    }
]

// Crear e insertar pantalla de inicio
const screenView = new GameStartScreen({
    screenOptions: screenOptions
})

oppenWorldEngine.screenView = screenView;
document.body.append(screenView)

🔄 Ciclo de Vida del Juego

El motor sigue un ciclo de actualización constante que maneja inputs, lógica de juego y renderizado.

Flujo Principal

  1. Inicialización: Se crean todas las instancias de personajes, mapas y sistemas.
  2. Configuración: Se registran los mapas en el motor y se configuran las relaciones entre personajes.
  3. Pantalla de Inicio: Se muestra el menú principal con las opciones configuradas.
  4. Inicio del Juego: Al seleccionar "New Game", el motor carga el primer mapa y comienza el loop principal.
  5. Game Loop: El motor actualiza constantemente el estado del juego (movimiento, colisiones, animaciones) y renderiza cada frame.
  6. Eventos: Las interacciones del usuario (teclado, clicks) disparan acciones que pueden cambiar el estado del juego, iniciar batallas o activar escenas narrativas.
